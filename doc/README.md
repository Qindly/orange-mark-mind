## API 规范

### 基础 URL

- 开发环境: `http://localhost:60100/api/v1`
- 生产环境: `https://your-domain.com/api/v1`

### 响应格式

所有 API 响应统一使用以下 JSON 格式：

```json
{
  "code": 0, // 业务状态码，0 表示成功
  "message": "success", // 状态描述
  "data": {} // 响应数据
}
```

### 错误码定义

| 错误码 | 描述                       |
| :----: | :------------------------- |
|   0    | 成功                       |
|  1001  | 参数错误                   |
|  1002  | 未授权（Token 无效或过期） |
|  1003  | 禁止访问（权限不足）       |
|  1004  | 资源不存在                 |
|  2001  | 用户已存在                 |
|  2002  | 用户名或密码错误           |
|  2003  | 账号已被禁用               |
|  2004  | Refresh Token 无效         |
|  3001  | 文档不存在                 |
|  3002  | 文件夹不存在               |
|  4001  | AI 配置不存在              |
|  4002  | AI API 调用失败            |
|  5000  | 服务器内部错误             |

## 🔐 认证机制：双 Token 无感刷新

### Token 类型

| Token                  | 有效期  | 存储位置                | 用途     |
| :--------------------- | :------ | :---------------------- | :------- |
| **Access Token (AT)**  | 15 分钟 | 前端内存/localStorage   | 接口认证 |
| **Refresh Token (RT)** | 7 天    | httpOnly Cookie + Redis | 刷新 AT  |

### 认证流程

```
┌─────────────────────────────────────────────────────────────────┐
│                         用户登录                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
         ┌────────────────────────────────────────┐
         │ POST /api/v1/auth/login                │
         │ Body: { username, password }           │
         └────────────────────────────────────────┘
                              │
                              ▼
         ┌────────────────────────────────────────┐
         │ 响应:                                   │
         │ - access_token (15min)                 │
         │ - refresh_token (7d, httpOnly Cookie)  │
         │ - expires_in: 900                      │
         └────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                       正常 API 请求                              │
│         Header: Authorization: Bearer <access_token>            │
└─────────────────────────────────────────────────────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │                   │
                    ▼                   ▼
            ┌───────────┐       ┌───────────────┐
            │ AT 有效    │       │ AT 过期 (401) │
            └───────────┘       └───────────────┘
                    │                   │
                    ▼                   ▼
            ┌───────────┐       ┌───────────────────────────────┐
            │ 返回数据   │       │ 前端自动调用                   │
            └───────────┘       │ POST /api/v1/auth/refresh     │
                                │ Cookie: refresh_token          │
                                └───────────────────────────────┘
                                        │
                                        ▼
                                ┌───────────────────┐
                                │ 返回新的 AT        │
                                │ (可选返回新的 RT)   │
                                └───────────────────┘
                                        │
                                        ▼
                                ┌───────────────────┐
                                │ 重试原请求         │
                                └───────────────────┘
```

### Redis 存储设计

| Key 格式                    | 值                         | TTL           | 说明                |
| :-------------------------- | :------------------------- | :------------ | :------------------ |
| `rt:{user_id}:{token_hash}` | `{device, ip, created_at}` | 7 天          | 存储有效的 RT       |
| `user:{user_id}:tokens`     | Set of token_hash          | 7 天          | 用户所有 RT 索引    |
| `blacklist:at:{token_hash}` | `1`                        | AT 剩余有效期 | AT 黑名单（登出后） |

### Token 操作 API

| 接口                      | 方法 | 说明                   |
| :------------------------ | :--- | :--------------------- |
| `/api/v1/auth/login`      | POST | 登录获取 Token         |
| `/api/v1/auth/register`   | POST | 注册新用户             |
| `/api/v1/auth/refresh`    | POST | 刷新 Access Token      |
| `/api/v1/auth/logout`     | POST | 登出（注销当前 Token） |
| `/api/v1/auth/logout-all` | POST | 登出所有设备           |
